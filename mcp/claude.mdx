Liftx does not currently provide an active trading MCP connection for Claude. No desktop configuration, remote connector registration, or command-line package is required or supported for this release.

The reserved `https://mcp.liftx.io/mcp` address must not be treated as an active server. Do not place Liftx API keys or TradingView capabilities in prompts or an unverified MCP configuration.

After activation, the guide will describe the supported authorization flow, account and instrument consent, separate read and trading permissions, receipt reconciliation, and revocation. Client-specific instructions will be verified against the supported Claude release before publication.

For current automation, use the [API](/api/overview) or [TradingView](/integrations/tradingview/overview). See the [MCP status](/mcp/overview) for the shared planned model.

Liftx does not currently provide an active trading MCP connection for ChatGPT. There is no connector URL, registration sequence, or tool list to configure in this release.

The reserved `https://mcp.liftx.io/mcp` address must not be treated as an active server. Do not enter Liftx API keys, TradingView capabilities, account passwords, or exchange credentials into a conversation.

When available, setup will use the supported client authorization flow with explicit Liftx consent for accounts, instruments, and operations. The final guide will explain read-only access, separately approved trading access, receipts, revocation, and limitations after end-to-end verification.

For current automation, use the [API](/api/overview) or [TradingView](/integrations/tradingview/overview). See the [MCP status](/mcp/overview) for the shared planned model.

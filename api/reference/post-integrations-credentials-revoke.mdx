## Authorization

Authenticated Liftx Settings session; available after entitlement expiry.

## Behavior

Revoke one account-owned credential by its `id`. Settings uses this operation for **Keys → Remove key** when an integration has multiple keys. Other credentials in the namespace remain authorized. To end the whole API, TradingView or MCP connection, use [Disconnect](/api/reference/post-integrations-bindings-revoke).

`200 {"revoked":true}` confirms revocation. `REVOCATION_UNCERTAIN` means an attempted update could not be confirmed; inspect metadata before any explicit retry. New handoffs through the revoked credential are blocked; owned protections and termination are not interrupted.

This is a session-owned application contract, not an ordinary API-key endpoint. Use [Settings → Integrations](https://app.liftx.io/settings/integrations). The public API base URL does not grant session access.

## Authorization

Authenticated Liftx Settings session; available after entitlement expiry.

## Behavior

200 revoked:true confirms revocation. REVOCATION_UNCERTAIN means an attempted update could not be confirmed; inspect metadata before any explicit retry. New handoffs are blocked once authority is revoked; owned protections and termination are not interrupted.

This is a session-owned application contract, not an ordinary API-key endpoint. Use [Settings → Integrations](https://app.liftx.io/settings/integrations). The public API base URL does not grant session access.

## Authorization

`read`; exact-link aggregate requires an unrestricted instrument policy.

## Behavior

Returns account reporting dimensions, including closed-only pairs. Optional search filters display pairs; follow next_cursor until empty. Reporting pair_id values are not execution instrument IDs.

## Request example

```http
GET /v1/dashboard/pairs?exchange_link_id=17&environment=demo&currency=USDT
Authorization: Bearer YOUR_API_KEY_FROM_PRIVATE_STORAGE
```

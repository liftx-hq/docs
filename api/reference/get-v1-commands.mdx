## Authorization

Any valid API key for its own integration namespace.

## Behavior

Returns at most 50 top-level receipts and nullable next_cursor. Pass the returned cursor unchanged for older commands. Group children are represented by their parent summary; request detail for child outcomes. This is namespace history, not all account Activity.

## Request example

```http
GET /v1/commands
Authorization: Bearer YOUR_API_KEY_FROM_PRIVATE_STORAGE
```

All IDs and dates are illustrative. URL-encode opaque query values and supply each allowed key once. Optional filters and their types appear in the generated schema below.

## Authorization

Authenticated Liftx Settings session; no API-key authorization.

## Behavior

Returns at most 100 active-first/recent credential metadata entries plus tradingview_available. Metadata never recovers a secret. Inspection remains available after entitlement expiry. Availability is an activation signal, not proof every market is ready.

This is a session-owned application contract, not an ordinary API-key endpoint. Use [Settings → Integrations](https://app.liftx.io/settings/integrations). The public API base URL does not grant session access.

## Request example

```http
GET /integrations/credentials
```

All IDs and dates are illustrative. URL-encode opaque query values and supply each allowed key once. Optional filters and their types appear in the generated schema below.

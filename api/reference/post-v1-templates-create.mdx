## Authorization

`templates:write`; account template authority.

## Behavior

Body limit is 64 KiB. The full codec requires identity/timestamp fields; creation replaces them with server-owned values and binds ownership to the authenticated account. No trading receipt or order execution occurs. After an ambiguous response, inspect the template list before explicitly retrying.

## Authorization

`read`; templates are account-owned.

## Behavior

Returns a bare array, including an empty array when no templates exist. It is not wrapped in success/data and not limited to the credential instrument. Template reads place no trades.

## Request example

```http
GET /v1/templates/list
Authorization: Bearer YOUR_API_KEY_FROM_PRIVATE_STORAGE
```

All IDs and dates are illustrative. URL-encode opaque query values and supply each allowed key once. Optional filters and their types appear in the generated schema below.

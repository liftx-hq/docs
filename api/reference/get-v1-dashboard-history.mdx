## Authorization

`read`; exact-link aggregate requires an unrestricted instrument policy.

## Behavior

Specify the link, its actual live/demo environment and a supported reporting currency. market is all, spot or futures; pair_id is a reporting identity. Supply before or after, never both, as positive canonical Unix seconds. Respect reporting coverage and temporary unavailability.

## Request example

```http
GET /v1/dashboard/history?exchange_link_id=17&environment=demo&currency=USDT
Authorization: Bearer YOUR_API_KEY_FROM_PRIVATE_STORAGE
```

All IDs and dates are illustrative. URL-encode opaque query values and supply each allowed key once. Optional filters and their types appear in the generated schema below.

## Authorization

`read`; link aggregates require an unrestricted instrument policy.

## Behavior

Returns a canonical positions page for one exact link. status defaults to active; offset defaults to 0, limit to 50 and maximum limit is 200. Respect has_more, incomplete and endpoint errors. Do not infer zero exposure from an incomplete page.

## Request example

```http
GET /v1/positions/list?exchange_link_id=17
Authorization: Bearer YOUR_API_KEY_FROM_PRIVATE_STORAGE
```

All IDs and dates are illustrative. URL-encode opaque query values and supply each allowed key once. Optional filters and their types appear in the generated schema below.

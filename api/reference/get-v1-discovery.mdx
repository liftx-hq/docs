## Authorization

Any valid ordinary API key; no additional scope.

## Behavior

Returns version, canonical action names, scopes, advertised request/pending/group bounds and MCP availability. Use `mcp_available` for feature detection when offering a connection. Discovery does not grant OAuth consent or replace linked-account checks.

## Request example

```http
GET /v1/discovery
Authorization: Bearer YOUR_API_KEY_FROM_PRIVATE_STORAGE
```

All IDs and dates are illustrative. URL-encode opaque query values and supply each allowed key once. Optional filters and their types appear in the generated schema below.

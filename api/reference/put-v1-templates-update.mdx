## Authorization

`templates:write`; account template authority.

## Behavior

Use the query id and a complete reviewed template. The server enforces account ownership. Success is 204 with no body. This endpoint has no trading-command idempotency key; reconcile after transport ambiguity.

## Response and errors

The generated response schema below is the wire contract. A successful response has no body; do not attempt JSON decoding. Inspect HTTP status and Content-Type before decoding failures; reused trading routes may return JSON or plain text. Authentication, entitlement and exact link/instrument restrictions apply in addition to endpoint validation. See [errors and recovery](/api/errors-and-limits).

Do not automatically repeat a mutation after transport ambiguity. Trading commands reuse the exact immutable identity; credential issuance and template writes require their documented metadata/read reconciliation.

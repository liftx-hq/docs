## Authorization

`read` for the exact position link/instrument.

## Behavior

Returns success/message/data with a canonical Position publication. All three supplied identity fields must describe the same authorized position. Attached OPEN, close, SL and TP orders are embedded; no separate external order engine is implied.

## Request example

```http
GET /v1/positions/get?id=11111111-1111-4111-8111-111111111111&exchange_link_id=17&instrument_id=COPY_EXACT_CATALOG_ID
Authorization: Bearer YOUR_API_KEY_FROM_PRIVATE_STORAGE
```

All IDs and dates are illustrative. URL-encode opaque query values and supply each allowed key once. Optional filters and their types appear in the generated schema below.

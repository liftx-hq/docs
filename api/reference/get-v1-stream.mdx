## Authorization

`read` in the upgrade Authorization header.

## Behavior

This HTTP GET upgrades to WebSocket (101). Send scoped JSON text controls and decode the documented versioned binary messages. Browser WebSocket clients cannot normally set the required header; do not move secrets into URLs. Mutations remain HTTP commands.

## Upgrade example

```http
GET /v1/stream
Authorization: Bearer YOUR_API_KEY_FROM_PRIVATE_STORAGE
Connection: Upgrade
Upgrade: websocket
Sec-WebSocket-Version: 13
Sec-WebSocket-Key: CLIENT_GENERATED_HANDSHAKE_NONCE
```

Use a WebSocket library to construct the handshake and verify its response. The client controls and complete channel codecs are in the [stream guide](/api/streams).

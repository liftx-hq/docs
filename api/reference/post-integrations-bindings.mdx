## Authorization

Authenticated Settings session and exact binding approval.

## Behavior

Create one restricted setup/credential for an exact link and instrument. Explicit position_mode and allow_market_terminate are required. Guided mode saves a complete position_request; advanced signals carry their own request. New issuance returns the one-time secret, binding and webhook_url.

This is a session-owned application contract, not an ordinary API-key endpoint. Use [Settings → Integrations](https://app.liftx.io/settings/integrations). The public API base URL does not grant session access.

## Authorization

`read`.

## Behavior

Returns only exact authorized links with registry exchange identity and `live`/`demo` environment. No exchange secrets are returned. Use the link ID as execution authority; do not substitute an exchange ID.

## Request example

```http
GET /v1/exchange-links
Authorization: Bearer YOUR_API_KEY_FROM_PRIVATE_STORAGE
```

All IDs and dates are illustrative. URL-encode opaque query values and supply each allowed key once. Optional filters and their types appear in the generated schema below.

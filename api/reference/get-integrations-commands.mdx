## Authorization

Authenticated Liftx Settings session.

## Behavior

Returns an account-owned receipt page, unlike the API namespace list. Up to 50 top-level receipts with nullable next_cursor; Events refresh is user-driven. Receipt semantics are unchanged.

This is a session-owned application contract, not an ordinary API-key endpoint. Use [Settings → Integrations](https://app.liftx.io/settings/integrations). The public API base URL does not grant session access.

## Request example

```http
GET /integrations/commands
```

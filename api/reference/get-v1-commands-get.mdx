## Authorization

Owning integration namespace; alternatively same-account `read` plus the exact authorized link/instrument.

## Behavior

Read an exact receipt UUID. Group detail includes up to 64 child targets; zero-target groups can omit targets. Other-namespace read permission does not grant mutation namespace authority. A receipt state never replaces actual position evidence.

## Request example

```http
GET /v1/commands/get?id=11111111-1111-4111-8111-111111111111
Authorization: Bearer YOUR_API_KEY_FROM_PRIVATE_STORAGE
```

All IDs and dates are illustrative. URL-encode opaque query values and supply each allowed key once. Optional filters and their types appear in the generated schema below.

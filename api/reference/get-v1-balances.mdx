## Authorization

`read`; link aggregates require an unrestricted instrument policy.

## Behavior

Returns exact fixed-point free balances, link identity and snapshot_complete. An absent asset in an incomplete snapshot is not a zero balance. This HTTP model preserves decimal coefficients/scales and should be used for exact sizing reconciliation.

## Request example

```http
GET /v1/balances?exchange_link_id=17
Authorization: Bearer YOUR_API_KEY_FROM_PRIVATE_STORAGE
```

All IDs and dates are illustrative. URL-encode opaque query values and supply each allowed key once. Optional filters and their types appear in the generated schema below.

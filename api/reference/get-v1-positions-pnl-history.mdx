## Authorization

`read` for the exact position.

## Behavior

Returns canonical history for one position. Optional after is a positive Unix-second boundary. Preserve decimal values and completeness/reset semantics; historical P&L is not proof that current execution completed.

## Request example

```http
GET /v1/positions/pnl-history?id=11111111-1111-4111-8111-111111111111
Authorization: Bearer YOUR_API_KEY_FROM_PRIVATE_STORAGE
```

All IDs and dates are illustrative. URL-encode opaque query values and supply each allowed key once. Optional filters and their types appear in the generated schema below.

## Authorization

`read` for the exact link/instrument.

## Behavior

Returns eligible settlement currencies in success/message/data. Use a valid choice for spot trading_currency. Do not substitute quantity_asset or a derivative margin setting.

## Request example

```http
GET /v1/symbols/trading-currencies?exchange_link_id=17&instrument_id=COPY_EXACT_CATALOG_ID
Authorization: Bearer YOUR_API_KEY_FROM_PRIVATE_STORAGE
```

All IDs and dates are illustrative. URL-encode opaque query values and supply each allowed key once. Optional filters and their types appear in the generated schema below.

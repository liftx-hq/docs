## Authorization

`templates:write`; account template authority.

## Behavior

Deletes the exact account-owned template, not a position or its orders. Success is 204 with no body; absent/inaccessible templates return the owner error. Reconcile an ambiguous response before explicitly repeating.

## Request example

```http
DELETE /v1/templates/delete?id=44444444-4444-4444-8444-444444444444
Authorization: Bearer YOUR_API_KEY_FROM_PRIVATE_STORAGE
```

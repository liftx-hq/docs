## Authorization

Same authenticated Settings session and pending operation.

## Behavior

Proof has exactly one of password or apple_token, with mfa_code when required. Apple proof must match the nonce/audience and already-linked subject. The approval is purpose/payload-bound and consumed once during issuance. Five proof attempts share the approval budget.

This is a session-owned application contract, not an ordinary API-key endpoint. Use [Settings → Integrations](https://app.liftx.io/settings/integrations). The public API base URL does not grant session access.

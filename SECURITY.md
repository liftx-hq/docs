# Security policy

Report suspected vulnerabilities privately to security@liftx.io. For ordinary setup assistance, contact support@liftx.io.

Include the affected page or contract path and a minimal synthetic reproduction. Do not include live credentials, private financial records, personal information, or exploit details in a public GitHub issue.

This repository contains public documentation only. Examples use synthetic identifiers and placeholder secrets. The hosted reference disables executable API playgrounds, request proxying, and browser credential forwarding.
